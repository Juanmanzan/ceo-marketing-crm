# CEO Marketing - Mini CRM

Mini CRM de clientes desarrollado como parte del desafío técnico de CEO Marketing.

## Tecnologías previstas

- Python
- Django
- SQLite
- HTML, CSS y JavaScript
- Docker
- GitHub Actions

## Funcionalidades previstas

- Registro de clientes.
- Listado de clientes.
- Edición y eliminación de clientes.
- Búsqueda por nombre o empresa.
- Filtros por estado.
- Dashboard con indicadores de clientes.

## Estado del proyecto

En desarrollo. Actualmente se está configurando el repositorio y la integración continua.
